# Gráfico de operación de compresores Parise y Schulz

Este proyecto representa gráficamente la operación de dos compresores en una configuración maestro-esclavo.

- **Parise:** compresor principal, que trabaja de forma constante.
- **Schulz:** compresor de apoyo al Parise.

El objetivo es mostrar la relación de trabajo entre ambos compresores.
